# ととのい整体院 ゆるり（架空店舗LP）

ポートフォリオ用に制作した、架空の整体院のランディングページです。
個人事業主・店舗のお客様向けに、「初回体験の予約」をゴールにしたLPの設計と実装をお見せするためのサイトです。

※ 店舗・人物・住所はすべて架空です。写真とイラストはAIで生成しています。

**公開URL**：https://shinme10.github.io/lp-yururi/

## 構成

```
index.html        … LP本体
css/style.scss    … スタイルの元ファイル（デザイントークン定義を含む）
css/style.css     … コンパイル後のCSS
js/main.js        … メニュー・FAQ・フォーム・スクロール演出（ライブラリ不使用）
img/              … 画像（WebP）
```

※ 生成元の原寸画像（PNG）とSCSSのソースマップはリポジトリに含めていません。

## 使っている技術

- HTML / SCSS / JavaScript（jQuery などのライブラリは不使用）
- デザイントークン（カラー・タイポグラフィ・余白・角丸・影）をSCSS変数とCSSカスタムプロパティで管理
- `clamp()` と `auto-fit` グリッドによるレスポンシブ対応（SPは767px以下）

## 実装のポイント

- **予約までの導線**：ファーストビュー・料金・CTA帯・フォームに予約ボタンを配置し、SPでは画面下に予約バーを固定
- **予約フォーム**：フォーカスが外れたとき・送信時にバリデーション。定休日（水曜）を選ぶとその場でエラー表示。送信中 → 完了パネルへ切り替え
  - 確認用に `?form=error` / `?form=complete` を付けると、各状態を固定表示できます
- **アクセシビリティ**：WCAG AAのコントラスト、キーボード操作（ドロワー内のフォーカス制御・Escで閉じる）、`aria-expanded` / `aria-invalid` の切り替え、`prefers-reduced-motion` への対応
- **表示速度**：画像をWebPに変換（約17MB → 約350KB）、`width` / `height` の指定によるレイアウトずれの防止、遅延読み込み、FV画像の先読み

## SCSSのコンパイル

VS Code の拡張機能「Live Sass Compiler」を使うか、次のコマンドでコンパイルします。

```
npx sass css/style.scss css/style.css
```
